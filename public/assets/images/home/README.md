# KISAS Home Assets

Source: `https://www.figma.com/design/nSgMPOfdRCDJ0ORTaj4uDc/KISAS?node-id=190-2`

These files were exported from the Figma MCP asset URLs for the home page design. Use these local files instead of temporary Figma asset URLs when implementing the production home page.

Path convention: page assets live under `public/assets/images/{pageURL}`. The `/` route uses `home`.

Keep the filenames stable unless the implementation is updated at the same time.
